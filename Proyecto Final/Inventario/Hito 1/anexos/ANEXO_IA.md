# ANEXO DE USO DE INTELIGENCIA ARTIFICIAL

## Herramienta utilizada

Durante el desarrollo del proyecto se utilizó ChatGPT como herramienta de apoyo para programación y documentación.

## Uso realizado

La herramienta fue utilizada principalmente para:

- Revisar y mejorar la estructura del proyecto.
- Apoyar la implementación de las estructuras de datos.
- Revisar algoritmos de búsqueda y ordenamiento.
- Proponer pruebas para verificar el funcionamiento del sistema.
- Apoyar la elaboración de pruebas de complejidad y benchmarks.
- Revisar y completar los docstrings y type hints.
- Apoyar la organización de la documentación del proyecto.
- Detectar y corregir errores encontrados durante las pruebas.

## Qué se solicitó a la herramienta

Se realizaron consultas relacionadas con:

- Implementación de un arreglo dinámico con crecimiento automático.
- Implementación de una matriz cuadrada escalable para las ubicaciones de la bodega.
- Implementación de búsqueda lineal y búsqueda binaria.
- Implementación de Bubble Sort y QuickSort.
- Integración de productos mediante archivos CSV.
- Elaboración de pruebas automatizadas con pytest.
- Comparación de las estructuras implementadas con las estructuras y funciones de la biblioteca estándar de Python.
- Documentación de complejidad temporal y espacial.

## Correcciones realizadas

Las propuestas generadas por la herramienta fueron revisadas y adaptadas al código existente.

Entre las correcciones realizadas durante el desarrollo se encuentran:

- Ajuste de nombres de atributos para coincidir con las clases implementadas.
- Corrección de la carga de productos desde CSV.
- Corrección de referencias a atributos de la matriz.
- Ajuste de las pruebas para trabajar correctamente desde el proyecto.
- Corrección de la integración del benchmark.
- Completar y corregir documentación y type hints.

## Verificación

El código generado o modificado con apoyo de IA fue revisado y comprobado mediante:

- Pruebas automatizadas con pytest.
- Pruebas manuales desde main.py.
- Carga y consulta de productos mediante productos.csv.
- Pruebas de escalabilidad con diferentes cantidades de elementos.
- Comparación de QuickSort con sorted().
- Comparación de ArregloDinamico con list.

Al finalizar el desarrollo, las pruebas automatizadas fueron ejecutadas satisfactoriamente:

**23 pruebas aprobadas.**
